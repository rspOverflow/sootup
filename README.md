# Sootup

A tool for managing the Carbon Programming Language toolchain

## Why did you name it "Sootup"?

I was inspired by `rustup` to build this tool and so I decided to name it `sootup` because soot is comprised mostly of carbon. 
Also it's because I'm not very good at naming things. So if you have a problem with it, go ahead and open up an issue with 
the label `better-name-idea`.
